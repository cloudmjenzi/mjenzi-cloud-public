What's in Mjenzi Cloud

Six building blocks. Use one or all of them.

They all share one private network, so they work together as one environment. Need GPUs? See AI.

Virtual servers

Linux and Windows virtual machines on fast NVMe storage, in sizes from small to very large.

Dedicated servers

A whole physical server just for you, for databases and software licensed per server.

Storage

Disks for your servers, plus S3-compatible object storage for files, archives and data.

Backup & disaster recovery

Veeam backup for your servers and data, with a copy in a second region if you need it.

Kubernetes

Managed clusters for container apps. We handle upgrades and monitoring.

Network & security

Private networks, links to your office or data centre, firewalls and 24/7 security monitoring.
